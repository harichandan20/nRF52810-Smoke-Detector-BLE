# nRF52810 Smoke Detector BLE

Embedded firmware development using Nordic nRF52810 and Zephyr RTOS.

## Project Tasks

### Task 01 - LED Blinking
Basic GPIO LED blinking.

### Task 02 - LED and Buzzer
LED and buzzer control.

### Task 03 - LED, Buzzer and Switch
Integrated GPIO control with a switch input.

## Development Environment

- MCU: Nordic nRF52810
- RTOS: Zephyr
- Language: C
- Build System: CMake and West
